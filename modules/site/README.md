# Lotline foundation

The homepage introduces Lotline for fictional Ridgeway Motors. It describes the forthcoming dealership operations app and links to the existing database health API. Staff sign in through the `staff` module, keep the lot through the `inventory` module, the customers through the `customers` module and the sales through the `sales` module; the dashboard belongs to a later feature.

`BootstrapPage` puts the theme's `TopBar` in the `header` region and its `BootstrapIntro` in `content`, through `PageDocuments`. Two blocks fill the rest of the drawer on every page: `NavigationBlock` places the sidebar (the site's name, then a link per area with its Heroicon, the current one marked from the request path; areas join as their pages land, and Inventory, Customers and Sales show only when `StaffSession`, which `site` requires `staff` for, holds a signed-in member) and `SiteFooterBlock` the footer line. The `header` region is a row: the page's `TopBar`, then the `staff` module's `AccountMenuBlock`. The components live in `themes/lotline/`: each template in `components/<Name>/`, each class in `src/Components/<Name>/`.

`ThemeGuidePage` answers `/theme`, the style guide, from `ThemeSamples`, which composes the sample services: charts, records (the list honours `q`, `status`, `sort` and `page`), filters, stock, forms, actions and parts. `ThemeGuidePost` checks the sample vehicle form (`ThemeEntry`) and answers 422 with each field's error, or 303 back to the guide; the delete and sign-out samples go back too. Nothing is stored. The sample account menu passes its own id stem, `sample-account`, and its own form ids, so `/theme` signed in holds each id once beside the header's menu. `ThemeSampleStock::tone()` and `ThemeEntry::problems()` avoid `match` over enum cases and `array_intersect_key` until the compiler carries AIC #164 and #165 land.

The framework serves `/assets/aic.css` (the bundled theme stylesheet), the pinned Tessera script and its map from `build/assets/`, with byte ranges, before the application is assembled. The native comparison steps cover health, a missing route, the homepage, those files, missing and traversal asset requests and a stylesheet range.

The site has no brand icon yet: browser requests for `/favicon.ico` return 404.
